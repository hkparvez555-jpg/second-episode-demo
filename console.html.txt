const ROUTES={overview:['Overview','overview',viewOverview],queue:['Clinical queue','queue',viewQueue],tests:['Test kits','tests',viewTests],orders:['Orders','orders',viewOrders],appts:['Appointments','appts',viewAppts],rules:['Rules and safety','rules',viewRules]};
function route(){const h=location.hash.slice(1);return ROUTES[h]?h:'overview'}
function render(top){
  const r=route();
  const qn=results.filter(x=>x.status==='review').length+flags.filter(f=>f.status==='open').length;
  $('#nav').innerHTML=Object.entries(ROUTES).map(([k,[l,i]])=>`<a href="#${k}" class="${k===r?'on':''}" ${k===r?'aria-current="page"':''}>${ic(i)}<span>${l}</span>${k==='queue'&&qn?`<span class="count">${qn}</span>`:''}</a>`).join('');
  $('#view').innerHTML=ROUTES[r][2]();
  if(top) window.scrollTo({top:0});
}
window.addEventListener('hashchange',()=>render(true));
document.addEventListener('click',e=>{
  const el=e.target.closest('[data-act]'); if(!el) return;
  const a=el.dataset.act, id=el.dataset.id;
  if(a==='openReview'){reviewing=id;render(true)}
  if(a==='closeReview'){reviewing=null;render()}
  if(a==='toReview'){reviewing=id}
  if(a==='release'||a==='repeat'){
    const r=results.find(x=>x.id===id); r.status='done'; reviewing=null;
    const k=kits.find(x=>x.id===id); if(k){k.stage=5;k.days=0}
    if(a==='repeat') kits.unshift({id,test:'Urine',stage:0,days:0,note:'Repeat kit'});
    render(); toast(a==='repeat'?'Released. New kit added to Ordered':'Released to '+id);
  }
  if(a==='call'){toast('Marked: phone '+id+' before release')}
  if(a==='ackFlag'){flags.find(f=>f.id===id).status='done';render();toast('Follow-up logged for '+id)}
  if(a==='nudge'){toast('Nudge sent to '+overdue[+el.dataset.i][0]);overdue.splice(+el.dataset.i,1);render()}
  if(a==='advance'){const k=kits.find(x=>x.id===id);k.stage++;k.days=0;delete k.note;render();toast(id+': '+STAGES[k.stage])}
});
render();
